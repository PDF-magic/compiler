# Emoji artwork

Bundled, unmodified 72-pixel PNG artwork from Twemoji v17.0.2, by Twitter and
other contributors, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The full license is in `LICENSE-GRAPHICS`.

Source: https://github.com/jdecked/twemoji/releases/tag/v17.0.2

`72x72.zip` contains the source release's `assets/72x72/*.png` files, stored by
filename. These are embedded into PDFs locally; rendering does not contact a CDN.

Source tarball SHA-256: `3678d74fc4e793b76cbc810c77195d08877b97afdcc9e8f1a812579d854dccc8`.
